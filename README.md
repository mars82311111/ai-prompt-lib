# AI Prompt Library 📚

> 高质量提示词库 - High-Quality Prompt Library

精选高质量AI提示词，提升你的 productivity。

## ✨ Features

- 🎯 **精选提示词** - 覆盖各行业场景
- 🔄 **持续更新** - 定期添加新提示词
- 📝 **分类清晰** - 易于查找和使用
- 🌐 **多语言支持** - 中英文提示词

## 🚀 Quick Start

```python
from ai_prompt_lib import PromptLibrary

lib = PromptLibrary()
prompt = lib.get("写作助手")
print(prompt)
```

## 📦 Installation

```bash
pip install ai-prompt-lib
```
